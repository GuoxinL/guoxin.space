# 06. IT (Integration Test)

> **项目适配（guoxin.space）**：本仓库无后端 / DB / MQ，**IT = 页面自动化测试（Playwright E2E，强制门禁）**，规范见 `.harness/docs/integration_test/integration_test.md` 与 `playwright.config.ts` / `e2e/`。下方通用模板残留（testcontainers / docker / req_id / trace_id）已移除，不适用。

> **目的**：在真实（或近真实）环境验证 `02-plan.md` 定义的所有 IT 用例（页面级交互 / 渲染 / 导航 / 交互态）。
> **输入**：已构建的产物（或已部署的站点）+ `02-plan.md` 的 IT 用例清单
> **输出**：每个用例的执行结果 + 关键断言证据
>
> ⚠️ **协同开发模式同样必须执行本步骤**——页面自动化聚焦本组件职责；不跳过。

## 3. 失败定位（fix loop 根因分类）

| # | 场景 | 失败现象 | 根因 | 修复 | 修复后状态 |
|---|------|---------|------|------|-----------|
| R1 | 鉴权门禁（4 例） | 已 seed admin token 仍被判未登录 → 列表/创建/周报/暗黑全失败 | e2e `seedAuth` 注入旧键 `worker_url`，但 `authWorkerUrl()` 真相源读 `wb_home_sk_set` → 注入被忽略，请求走真实 Worker | `seedAuth` 改为注入 `wb_home_sk_set`（JSON 含 `worker: https://mock.todo.worker/`） | ✅ |
| R2 | 列表渲染（:127） | `.td-title` 选择器 0 匹配；首卡进度条 hidden | ① 标题类是 `.td-card-title`（`.td-title` 是页头 H1）② 首卡 progress 0% 进度条 width 0 不可见 | 断言改定位「写需求文档」卡内 `.td-bar-fill` | ✅ |
| R3 | 暗黑断言（:164） | `.td-page` 背景透明 | `.td-page` 仅 padding 无背景；表面令牌在 `.td-card` | 断言改 `.td-card` 背景 ≠ 透明 | ✅ |
| R4 | 日历月线（:189 前置） | `fetchMonth` 带 `?y=&m=` query，route 精确匹配漏 → `ERR_EMPTY_RESPONSE` 无线条 | month route 缺 query 通配 | `page.route(\`${MOCK_WORKER}api/todo/month*\`)` 加 `*` | ✅ |
| R5 | 标签/进度筛选 URL 未同步（真实缺陷） | 点标签后 URL 不写 `?tag=t1` | `useVisibleTask$` 用 `void x.value` 读信号，Qwik 未自动 track → `syncUrl` 不重跑 | 改用显式 `track(() => x.value)` 六个信号 | ✅ |
| R6 | 深链 `?todo=` 被剥（真实缺陷·TodoPage） | 直接 `goto('/todo?todo=todo-1')` 或日历点击后 URL 落 `/todo`，编辑弹窗不开 | mount 时 track 任务首跑即 `syncUrl()`，此刻 `reload()` 异步未回填 `editing`，`syncUrl` 把 query `replaceState('/todo')` 剥掉 | 加 `urlSynced` 首跑守卫：mount 当次跳过 `syncUrl`，待 `reload()` 回填 `editing` 后再由 track 触发写回 `?todo=` | ✅ |
| R7 | 日历跨路由深链丢 query（真实缺陷·CalendarPanel） | `nav(new URL('/todo?todo='+id, location.href))` 后 URL 落 `/todo`（无 query） | Qwik City 1.20 client router 仅**同路径**导航保留 query（`lib/index.qwik.mjs:916-918` `isSamePath(trackUrl, prevUrl)` 判定）；跨路由（`/toolbox/calendar`→`/todo`）不保留，用服务端 endpoint href 做 `history.pushState` 把 query 吃掉 | CalendarPanel 改用真实导航 `location.href = new URL('/todo?todo='+id, location.href).href`（full reload，保 query 且可书签化）；移除冗余 `useNavigate` 导入 | ✅ |
| R8 | 全量 notes/running 各 1 例（环境性） | notes 详情页 `.md-img` 不可见 / running「年度热力图」区块不可见 | 两用例均依赖外网（GitHub raw / Worker），未 mock；本沙箱浏览器系统代理端口无服务连不上 | **非代码问题**：CI runner 有真实外网，会通过；本地仅网络受限 | ⚠️ 环境性，不阻 CI 门禁 |

> 失败处理：R1–R7 全部为代码/用例问题 → 修复后按 `05-deploy.md` §5 amend + force-push 重部署闭环；R8 环境性，登记不修。

## 决策框架

1. **真实渲染优先**：用真实构建产物 / 线上站点验证，不用构造数据假装通过。
2. **异常注入**：主动触发 404 / 空数据 / 网络不可达（如 Running Worker 阻断），看页面降级是否符合预期。
3. **问题不留尾**：所有 ❌ 用例必须有根因 + 修复 + 复测，不能"稍后补"。
4. **断言为证**：每个用例必须贴出关键断言（DOM 文本 / 交互态 `getComputedStyle` 结果）或 Playwright 报告；没有证据 = 没做 IT = 驳回重测。
