## 关键决策备忘

> **跨阶段共享的关键上下文**。仅记录影响后续步骤的决策，避免恢复时还要翻阅历史阶段文件。

- **D1｜行头 `+/−` 语义 = 展开/收起子任务列表**（用户 2026-09-17 拍板）。未展开显示 `+`，已展开显示 `−`。**不是**完成开关。
- **D2｜任务完成开关改到「标题前的方块勾选」**（☐ 未完成 / ☑ 已完成）。点击 = 关闭或重新打开任务。—— D1 的配套决定，否则「任务开启关闭」失去入口。
- **D3｜子任务编辑器放行内展开区**（用户拍板）。从 `TodoModal` 抽出为 `SubtaskEditor`，复用其标题 / 权重 / 滑块 / 删除 UI。
- **D4｜日历页点击弹「只读预览卡片 + 跳转按钮」**（用户拍板）。**不做**跨页写数据；`CalendarPanel` 现有 `location.href = /todo?todo=<id>` 真实导航改为弹卡内的显式跳转按钮。
- **D5｜关闭任务时强制所有子任务进度置 100%**，再写 `completedAt`（用户拍板）。保证「已完成」在列表进度条与日历线条颜色上自洽。
- **D6｜新增 `lib/todo/write-queue.ts` 合并写盘**（400ms debounce + 串行 + 值未变跳过）。原地编辑把「保存」从显式点击变为高频隐式行为，而 Worker `/api/todo/save` 每次调用都会写一次 GitHub 仓库，必须合并。
- **D7｜深链 `?todo=<id>` 语义改为「定位 + 高亮 + 自动展开」**（不再打开弹窗）。
- **D8｜`openNew` 的 UTC 日期 bug 顺带修复**：`new Date().toISOString().slice(0,10)` → 本地日期（北京时间 00:00–08:00 会算成前一天）。抽 `mutate.ts` 的 `localDay()` 纯函数统一。
- **D9｜「重新打开」= 仅清 `completedAt`，子任务进度保持不变**（不做破坏性清零）。进度 100% + 未完成是可接受组合：颜色表达「子任务都做完了」，删除线表达「任务已关闭」。
- **D10｜`calcProgress` 算法零改动**。D5 的「关闭时子任务全 100%」通过写**数据**达成，不动算法——否则既有 `progress.test.ts` 16 例会红，且会牵动日历线条颜色语义。
- **D11｜写盘队列不能在 `useConstant` 里持有**（实测构建失败）。`useConstant` 的值进入 Qwik 序列化图（组件 `$seq$` 写进 HTML），队列对象含 `push`/`flush` 函数 → SSG 抛 `Code(3)`、`/todo/` 预渲染失败。改为客户端 `useVisibleTask$` 创建 + `useSignal` 承载。
- **D12｜草稿行不能用「signal 置 null」退场**。`{draft.value && <TodoRow todo={draft.value}/>}` 下 props 惰性求值会取到 null → 组件崩溃 → 整页 DOM 冻结。改为 `draft` 恒非 null（`EMPTY_TODO`）+ `hasDraft` 标志控制，且渲染用**三元同槽 + 固定 key**（两个相邻 `{cond && <Comp/>}` 会让 Qwik 残留上一分支 DOM）。
- **D13｜草稿行标题输入用非受控**（提交时读 DOM）。动态挂载行上受控 input 的 signal 与 DOM 不同步（已排除 `fill()` 因素），提交会读到空串、回车被误判为「丢弃」。
- **D14｜独立 `$()` 定义的 QRL 之间不能互相引用**。Qwik optimizer 不把另一个独立 QRL 加入捕获列表，运行时报 `xxx is not defined`（JSX 里的 inline handler 引用独立 QRL 则正常）。

## 风险速览

| # | 风险 | 严重度 | 缓解 |
|---|------|-------|------|
| 1 | 原地编辑提交频率高 → Worker 每次 `save` 写一次 GitHub 仓库，污染提交历史 | 🔴 高 | D6 写盘队列（debounce 合并 + 串行 + 值未变跳过） |
| 2 | 移除 `TodoModal` 后既有 e2e 用例失效（`todo.spec.ts` 5 条依赖 `.td-card` / `.td-modal`） | 🟡 中 | 同步重写对应用例，断言改为行 / 原地编辑 / POST 请求体 |
| 3 | 行内编辑草稿与 `reload()` 异步回填互相覆盖 | 🟡 中 | `useTask$` track + `editing` 守卫，编辑中的字段不接收 props 覆盖 |
| 4 | 标签回车创建需同时写 `tags.json` 与当前 todo，可能产生半成功状态 | 🟡 中 | 先写 `tags.json` 成功后再勾选写 todo；失败回滚内存态并 toast |
| 5 | CSS 新增量大且行内编辑涉及 `:hover`/`:focus-visible` 态 | 🟡 中 | 按 C-23 用 `getComputedStyle` 回读 hover 态；占位符色不进 `--td-input` 冲突 |
