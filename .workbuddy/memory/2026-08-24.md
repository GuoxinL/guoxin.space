## SVG vs PNG 垫底图实测（用户问 SVG 大小 / 转 PNG / 压缩可行性）

- **GitHub raw 实测支持 gzip**（Content-Encoding: gzip，829KB activities.json 实际传输 331KB）→ SVG 网络传输只看 gzip 体积。
- 全量 345K 点、1600x1000、zoom13 Mercator fit 对比：
  - SVG 浮点相对坐标(%.1f)：raw 2.9MB / gzip 116.6KB（小数尾数破坏重复性，gzip 效果差）
  - SVG 整数相对坐标(round)：raw 1.36MB / gzip 32.2KB ← 零依赖方案最佳
  - **PNG 1600x1000 线宽2 无抗锯齿：14KB（生成 0.4s）**；线宽1：13KB；800x500：4KB
  - PNG supersample 2x/4x 抗锯齿：86/89KB（生成 0.8/1.2s）
- 结论：**PNG 垫底最优**（14KB < SVG gzip 32KB，位图解码最快）；SVG 整数坐标是零依赖备选。PNG 仅作垫底，点位加载后切矢量层，投影参数一致零跳动。CI 需加 pip install pillow。
