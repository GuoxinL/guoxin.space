
## 1. 项目概述

为个人主页 `guoxin.space` 增加 TODO 列表模块，并与现有日历模块深度融合。支持子任务、标签分类、双层进度追踪、时间跨度线条展示、周报导出。整个 TODO 模块通过 GitHub OAuth 登录保护，数据存放于自有仓库中。

---

## 2. 架构与存储

### 2.1 总体架构

- **仓库**：自有 GitHub 仓库（私有或受控），TODO 数据作为仓库内的一部分
- **鉴权**：GitHub OAuth 登录，未登录用户无法看到 TODO 模块入口及任何数据
- **数据访问**：登录后通过服务端代理（或 Serverless 函数）读取/写入仓库中的 JSON 数据文件
- **部署**：静态站点 + 服务端代理，无纯前端跨域问题

### 2.2 存储结构

纯文本

纯文本

```
app/src/data/todo/
├── tags.json                  # 标签定义（全局）
├── index/                     # 月索引（用于日历快速渲染）
│   ├── 2026-09.json
│   ├── 2026-10.json
│   └── ...
├── 2026-09-15.json            # 当天创建的 todo 列表
├── 2026-09-16.json
├── 2026-09-17.json
└── ...
```

- 按 `createdAt` 日期归档，文件名为 `YYYY-MM-DD.json`
- 某天无任务则不生成文件
- 后续修改始终写回原文件（通过 `updatedAt` / `lastOperatedAt` 追踪）

### 2.3 月索引文件

**index/YYYY-MM.json**​ 存储该月起始的所有 TODO 摘要（不重复存储跨月条目）：

json

json

```
[
  {
    "id": "todo-001",
    "title": "重构个人主页",
    "tags": ["work"],
    "startDate": "2026-09-15",
    "endDate": "2026-09-20",
    "progress": 60,
    "completedAt": null
  }
]
```

- 索引只存摘要字段：`id`、`title`、`tags`、`startDate`、`endDate`、`progress`、`completedAt`
- 详情（subtasks）仍在每日文件里
- 日历渲染只读索引，点击线条/日期时才加载详情
- 跨月线条：索引只存起始月，渲染时通过 `endDate` 判断是否延续到下一月，不重复存储
- 创建/更新 TODO 时同步更新对应月份索引

## 3. 数据模型

### 3.1 tags.json

json

json

```
[
  { "id": "work", "name": "工作" },
  { "id": "life", "name": "生活" },
  { "id": "study", "name": "学习" }
]
```

- 仅含 `id` 和 `name`，无颜色字段
- 支持前端自定义创建、编辑、删除标签
- 历史 todo 通过 `tags: ["work"]` 引用 id

### 3.2 YYYY-MM-DD.json（每日 todo 文件）

json

json

```
[
  {
    "id": "todo-001",
    "title": "重构个人主页",
    "tags": ["work"],
    "startDate": "2026-09-15",
    "endDate": "2026-09-20",
    "createdAt": "2026-09-15T10:00:00",
    "updatedAt": "2026-09-17T14:00:00",
    "lastOperatedAt": "2026-09-17T14:00:00",
    "completedAt": null,
    "subtasks": [
      {
        "id": "sub-001-1",
        "title": "设计新布局",
        "weight": 30,
        "progress": 100,
        "updatedAt": "2026-09-17T11:00:00"
      },
      {
        "id": "sub-001-2",
        "title": "实现 TODO 组件",
        "weight": 50,
        "progress": 60,
        "updatedAt": "2026-09-17T14:00:00"
      },
      {
        "id": "sub-001-3",
        "title": "接入数据源",
        "weight": 20,
        "progress": 0,
        "updatedAt": "2026-09-15T10:00:00"
      }
    ]
  }
]
```

|字段|说明|
|---|---|
|`id`|Todo 唯一标识|
|`title`|任务标题|
|`tags`|标签 id 数组|
|`startDate`|任务开始日期（`YYYY-MM-DD`）|
|`endDate`|任务结束日期（`YYYY-MM-DD`），null 表示单日任务|
|`createdAt`|创建时间（本地时间，ISO 8601）|
|`updatedAt`|内容最后更新时间（本地时间）|
|`lastOperatedAt`|最后操作时间（本地时间，用于排序）|
|`completedAt`|完成时间，null 表示未完成|
|`subtasks`|子任务数组（自包含）|

**子任务字段：**

|字段|说明|
|---|---|
|`id`|子任务唯一标识|
|`title`|子任务标题|
|`weight`|权重（正整数，默认 1）|
|`progress`|进度（0/25/50/75/100，滑块五档）|
|`updatedAt`|最后更新时间（本地时间）|

## 4. 进度计算规则

### 4.1 子任务进度

- 通过滑块设置，仅限五档：`0 | 25 | 50 | 75 | 100`
- 手动调整，无自动推算

### 4.2 Todo 总进度（加权平均）

纯文本

纯文本

```
总进度 = Σ(子任务进度 × 子任务权重) / Σ(子任务权重)
```

- 无子任务时：总进度 = `completedAt` 有值 ? 100 : 0
- 示例：`(100×30 + 60×50 + 0×20) / 100 = 60%`

### 4.3 自动完成

- 总进度达到 **100%**​ 时，自动填充 `completedAt = 当前本地时间`
- 标记为完成后，进度锁定不可再改（除非手动"重新打开"将 `completedAt` 置 null）

## 5. 功能需求

### 5.1 TODO 管理

|操作|说明|
|---|---|
|创建|输入标题、选择标签、设定起止日期、设定子任务|
|编辑|修改标题、增删子任务、调整权重、修改起止日期|
|删除|**硬删除**，直接从文件中移除该 todo，同步更新月索引|
|重新打开|将已完成的 todo 重置为进行中（`completedAt` 置 null）|

### 5.2 子任务管理

- 每个 todo 下子任务数量不限
- 支持增删改
- 权重默认为 1，可手动设置正整数
- 进度通过滑块调整（五档）

### 5.3 标签管理

- 支持前端自定义创建标签（输入名称，自动生成 id）
- 支持编辑标签名称
- 支持删除标签
- 标签数据实时同步至 `tags.json`

### 5.4 标签筛选

- 首页/列表页展示所有标签，点击标签筛选对应 todo
- 支持"全部"查看
- 多标签时为**或**关系（含任一选中标签即展示）

### 5.5 进度筛选 & 排序

|筛选|条件|
|---|---|
|未开始|总进度 = 0%|
|进行中|0% < 总进度 < 100%|
|已完成|总进度 = 100%|

|排序|依据|
|---|---|
|最近操作|`lastOperatedAt` 降序|
|进度升序|总进度从低到高|
|进度降序|总进度从高到低|
|创建时间|`createdAt` 降序|

### 5.6 周报导出

**触发方式：**​ 选择标签 → 选择时间范围（默认本周一 ~ 周日）→ 点击导出

**导出格式：**​ Markdown / 纯文本 / HTML（可选）

**导出内容（Markdown 示例）：**

markdown

markdown

```
## 周报 — 工作 (2026-09-15 ~ 2026-09-21)

### 📊 总体统计
- Todo 总数：5
- 已完成：2 | 进行中：2 | 未开始：1
- 平均进度：58%

### 📋 任务明细
| 任务 | 进度 | 子任务完成 | 起止日期 |
|------|------|-----------|----------|
| 重构个人主页 | 60% | 1/3 | 09-15 ~ 09-20 |
| 写技术博客 | 100% | 2/2 | 09-16 |

### 📈 完成时间线
- 09-16 写技术博客 → 100%（子任务全部完成）
```

**附加功能：**

- 「复制到剪贴板」按钮，方便直接粘贴到飞书/钉钉/微信
- 可选附带当周日历截图

### 5.7 URL 状态同步

- 筛选条件、选中日期、弹窗状态同步到 URL 参数
- 示例：`/calendar?date=2026-09-17&todo=todo-001`
- 示例：`/todo?tag=work&filter=doing&sort=progress`
- 刷新不丢失状态，可复制链接跳转

### 5.8 快捷键

|操作|快捷键|
|---|---|
|新建 TODO|`N`|
|保存编辑|`Cmd/Ctrl + S`|
|关闭弹窗|`Esc`|
|切换日历/TODO 视图|`Tab` 或 `1`/`2`|
|切换标签筛选|`T` 后方向键|
|快速搜索|`/` 或 `Cmd+K`|

## 6. 日历融合

### 6.1 视觉设计

月视图每个日期格子内，在节假日文字下方展示 TODO 线条：

纯文本

纯文本

```
┌──────────────────┐
│  15   中秋节     │  ← 节假日（红色/金色，所有人可见）
│ ████████████████ │  ← TODO 线条（登录后可见）
│ ▓▓▓▓▓▓░░░░░░░░░░ │  ← 第二根线条（堆叠）
└──────────────────┘
```

**线条规则：**

|属性|说明|
|---|---|
|位置|日期格子内部，节假日文字下方|
|高度|约 6-8px|
|圆角|起始日左圆角，结束日右圆角|
|颜色|按进度自动着色：红(<30%) → 黄(30-70%) → 绿(>70%)|
|内部填充|线条内部按进度比例实心/空心|
|多任务堆叠|上下排列，最多 3 条，超出显示"+N"|
|跨月|截断到月视图范围内显示|

### 6.2 交互

|操作|行为|
|---|---|
|Hover 线条|浮窗显示：标题、标签、进度、起止日期|
|点击线条|侧边/弹窗面板展开，显示完整 TODO（**可直接编辑**：改标题、调进度、增删子任务、改起止日期）|
|点击日期格子空白处|显示该天所有 TODO 列表|
|拖拽线条边缘|调整 `endDate`（延长/缩短任务）|
|拖拽整条线条|整体移动起止日期|
|移动端长按|代替 hover，显示浮窗|
|移动端拖拽|长按后拖动，或提供"编辑日期"按钮作为备选|
|小屏降级|线条文字放不下时降级为圆点，点击展开|

### 6.3 鉴权分层

|状态|日历行为|
|---|---|
|未登录|只显示节假日，无 TODO 痕迹，点击日期提示登录|
|已登录|显示线条，可交互，可编辑|

- 无 todo 时显示引导文案 + 创建按钮
- 筛选无结果时显示"暂无匹配任务"
- 索引文件不存在 → 返回空列表

- 连续完成 TODO 天数 → 日历上显示 🔥 streak
- 当月完成率 100% → 月标题旁加个 🏆
